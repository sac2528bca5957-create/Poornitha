EduGenie: Google Gemini Powered Learning Assistant

EduGenie is a lightweight AI-powered educational assistant that simplifies learning through generative AI. 
Designed for students of all academic levels, EduGenie enables users to:
Ask questions and receive smart, concise answers
Understand complex concepts through simplified explanations
Generate quizzes from topics or text
Receive personalized learning recommendations
Summarize large educational passages
Built with FastAPI for the backend and a simple HTML+CSS frontend, EduGenie leverages lightweight and 
cloud-based AI models for local efficiency and cloud power.It works well on devices like the
Mac M1, making it accessible to a broad range of learners and developers.
